01 / Two modes

Two ways to think.
One assistant.

Nao is designed around flexibility. Local mode keeps useful capabilities on the device, while online mode expands what Nao can do when a connection is available.

Local mode

Useful without the cloud.

Run a local model for selected conversations and actions when you want an offline experience.

Online mode

More context when connected.

Use connected AI capabilities for richer answers and tasks that benefit from current information.

02 / Everyday use

03 / Regional by design

Useful where you actually live.

Some of Nao’s most interesting ideas come from regional services: utilities, everyday information and integrations that global assistants often ignore. These capabilities can expand over time without defining the whole product.
